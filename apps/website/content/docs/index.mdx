**medmark** is a CLI tool that converts Medium exported archives into Markdown (or MDX) files, ready to drop into any
static-site framework — Next.js, Astro, Hugo, and more.

## Let an agent do it

If you use a coding agent, you can hand it the whole migration — conversion, a blog to put the posts in, and the deploy:

```bash
npx skills add brionmario/medmark
```

> "Convert my Medium export to Markdown and get it hosted."

See [Agent Skill](/docs/agent-skill) for what it runs, and [Docs for AI](/docs/llms) for `llms.txt` and the Markdown
version of every page.

## What it does

- Parses Medium's HTML export format
- Generates clean Markdown with YAML front matter (slug, title, date, tags, images, and more)
- Downloads and remaps images locally or preserves remote CDN URLs
- Inlines GitHub Gists and embedded tweets into the Markdown body
- Builds a [content registry](/docs/registry) — a `registry.json`/`registry.ts` manifest, an RSS feed, and a sitemap
- Supports custom templates so you control the output shape
- Skips reply posts and optionally exports drafts

## How it works

```bash
npx medmark
```

On first run medmark creates a `medmark/` workspace in your current directory, then walks you through a short
interactive prompt to point it at your Medium export archive.

## Workspace layout

After `medmark init` (or the first `medmark` run):

```
my-project/
├── medmark/
│   ├── medium-export/   ← paste your Medium export's posts/ folder here
│   └── templates/       ← optional custom templates
└── .medmark/
    └── logs/            ← debug logs
```

The output folder (`medmark/output/` by default) is created by the conversion run itself, not by `init`. Alongside the
converted posts it contains a `conversion_report.json` and, unless disabled, the generated registry files.
