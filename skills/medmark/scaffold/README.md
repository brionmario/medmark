# medmark blog

A minimal [Astro](https://astro.build) site for posts generated by [medmark](https://github.com/brionmario/medmark).

## Quick start

1. Copy your medmark output into `content/posts/` — one folder per slug, each with an `index.md`:

   ```bash
   cp -R ../medmark/output/. content/posts/
   ```

2. Put your blog's name and description in `src/site.json`.

3. Run it:

   ```bash
   npm install
   npm run dev
   ```

   <http://localhost:4321>

## Build and deploy

```bash
npm run build    # static site in dist/
npm run preview  # serve the production build
```

`dist/` is plain static output, so any static host works. Set your public URL first — either `site` in
`astro.config.mjs` or a `SITE_URL` environment variable — so canonical links and the RSS feed are absolute.

- **Vercel** — `npx vercel deploy --prod`
- **Netlify** — `npx netlify deploy --prod --dir dist`
- **Cloudflare Pages** — `npx wrangler pages deploy dist`
- **GitHub Pages** — set `site` and `base` in `astro.config.mjs`, then deploy with
  [`withastro/action`](https://github.com/withastro/action)

## What's here

```
content/posts/              your medmark output (one folder per slug)
public/                     static files (copy LOCAL images here)
src/site.json               blog title, description, author
src/content.config.ts       lenient schema over medmark front matter
src/layouts/Base.astro      page shell, meta tags
src/lib/posts.ts            sorting, drafts, author/date helpers
src/pages/index.astro       post list
src/pages/posts/[...slug].astro
src/pages/rss.xml.ts        RSS feed
src/styles/global.css       all the styling, light + dark
```

Drafts (`draft: true`) show in `npm run dev` and are left out of production builds.

Images default to Medium's CDN (`imageStorageStrategy: 'REMOTE'`). If you generated with `'LOCAL'`, copy the `resources`
folders into `public/` so the paths resolve.

It is deliberately small — edit `global.css` and the two page files to make it yours.
