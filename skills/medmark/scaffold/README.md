# Personal blog starter

A small, production-ready [Next.js](https://nextjs.org) blog for posts generated by
[medmark](https://github.com/brionmario/medmark). App Router, TypeScript, Tailwind CSS v4, statically exported to one
config file to make it yours.

## Quick start

1. Copy your medmark output into `content/posts/`, one folder per slug, each with an `index.md`:

   ```bash
   cp -R ../medmark/output/. content/posts/
   ```

2. Make it yours in `site.config.ts`:

   ```ts
   export const site: SiteConfig = {
     name: 'Ada Lovelace',
     theme: 'clay',
     role: 'Compiler engineer',
     location: 'Cambridge, UK',
     tagline: 'Notes on compilers, and the occasional detour.',
     description: 'Essays on compilers and language design by Ada Lovelace.',
     url: 'https://ada.dev',
     avatar: '/avatar.jpg',
     about: ['I build language tooling…'],
     now: 'Working on an incremental type checker.',
     work: [{role: 'Principal Engineer', company: 'Analytical Engines', period: '2021 to now'}],
     nav: [
       {label: 'Writing', href: '/'},
       {label: 'About', href: '/about/'},
     ],
     links: [
       {label: 'GitHub', href: 'https://github.com/ada'},
       {label: 'RSS', href: '/rss.xml'},
     ],
   };
   ```

   Every section hides itself when its field is empty, so fill in what you want and leave the rest alone. Then swap
   `public/favicon.svg` for your own mark.

   `theme` picks one of four palettes: `clay`, `ink`, `forest` or `plum`. Run the dev server and open
   <http://localhost:3000/themes> to see them side by side in light and dark; the page exists only in dev.

3. Run it:

   ```bash
   npm install
   npm run dev
   ```

   <http://localhost:3000>

## What you get

- Posts grouped by year, with excerpts that strip the title Medium repeats into the body
- Post pages with tags, reading time and older/newer links, plus a page per tag
- An about page driven by the same config: bio, what you're working on now, recent roles
- `/rss.xml`, `/sitemap.xml`, `/robots.txt` and a 404 page
- Open Graph, Twitter and canonical tags on every page
- Four palettes, light and dark, switched with one line, plus a toggle that remembers the reader's choice and follows
  their OS until it's used
- Drafts (`draft: true`) visible in `npm run dev`, dropped from production builds

Posts are rendered at build time with remark/rehype and raw HTML enabled, and **not** MDX, because Medium exports carry
HTML (figures, captions, iframes) that MDX rejects. Code blocks are highlighted by Shiki in both themes.

## Build and deploy

```bash
npm run build    # static site in out/
npm run start    # serve the built out/ directory
```

Set your public URL first, either `url` in `site.config.ts` or a `SITE_URL` environment variable, so canonical links,
RSS and the sitemap are absolute.

`out/` is plain static output, so any host works:

- **Vercel**: `npx vercel deploy --prod`
- **Netlify**: `npx netlify deploy --prod --dir out`
- **Cloudflare Pages**: `npx wrangler pages deploy out`
- **GitHub Pages**: set `basePath: '/<repo>'` in `next.config.ts` for a project site, add an empty `.nojekyll` to `out/`
  (otherwise `_next/` is hidden and the site loads unstyled), then deploy with `actions/deploy-pages`

## Layout

```
content/posts/              your medmark output (one folder per slug)
public/                     static files: favicon, avatar, LOCAL images
site.config.ts              name, role, tagline, about, work, links
app/themes.ts               the four palettes; colour lives here and nowhere else
app/globals.css             post body styling, type scale
app/themes/page.tsx         dev-only gallery of the palettes
app/layout.tsx              page shell, fonts, meta tags
app/page.tsx                home: intro and post list
app/about/page.tsx
app/posts/[...slug]/page.tsx
app/tags/[tag]/page.tsx
app/not-found.tsx
app/components/             header, footer, post list, theme toggle
app/lib/posts.ts            front matter, sorting, drafts, excerpts, tags
app/lib/markdown.ts         Markdown → HTML pipeline
app/rss.xml/route.ts        RSS feed
app/sitemap.ts, app/robots.ts
```

Images default to Medium's CDN (`imageStorageStrategy: 'REMOTE'`). If you generated with `'LOCAL'`, copy the `resources`
folders into `public/` so the paths resolve.

Everything is deliberately small: one stylesheet, a handful of components. Change them.
