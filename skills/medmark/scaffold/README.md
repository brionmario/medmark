# Personal blog starter

A small, production-ready [Astro](https://astro.build) blog for posts generated by
[medmark](https://github.com/brionmario/medmark). Plain HTML and CSS, no framework on the page, nothing to configure
beyond your own name.

## Quick start

1. Copy your medmark output into `content/posts/` — one folder per slug, each with an `index.md`:

   ```bash
   cp -R ../medmark/output/. content/posts/
   ```

2. Make it yours in `src/site.json`:

   ```json
   {
     "title": "Ada Lovelace",
     "tagline": "Notes on compilers, and the occasional detour.",
     "description": "Essays on compilers and language design by Ada Lovelace.",
     "url": "https://ada.example.com",
     "author": {"name": "Ada Lovelace", "bio": "Compiler engineer.", "avatar": "/avatar.jpg"},
     "nav": [{"label": "Posts", "href": "/"}],
     "links": [
       {"label": "GitHub", "href": "https://github.com/ada"},
       {"label": "RSS", "href": "/rss.xml"}
     ]
   }
   ```

   Then swap `public/favicon.svg` for your own mark.

3. Run it:

   ```bash
   npm install
   npm run dev
   ```

   <http://localhost:4321>

## What you get

- Posts grouped by year, with excerpts that strip the title Medium repeats into the body
- Post pages with tags, reading time and older/newer links
- `/rss.xml`, `/sitemap.xml`, `/robots.txt` and a 404 page
- Open Graph and canonical tags on every page
- Light and dark, following the reader's system setting
- Drafts (`draft: true`) visible in `npm run dev`, hidden in production builds

## Build and deploy

```bash
npm run build    # static site in dist/
npm run preview  # serve the production build
```

Set your public URL first — `site` in `astro.config.mjs`, or a `SITE_URL` environment variable — so canonical links, RSS
and the sitemap are absolute.

`dist/` is plain static output, so any host works:

- **Vercel** — `npx vercel deploy --prod`
- **Netlify** — `npx netlify deploy --prod --dir dist`
- **Cloudflare Pages** — `npx wrangler pages deploy dist`
- **GitHub Pages** — set `site` and `base` in `astro.config.mjs`, then deploy with
  [`withastro/action`](https://github.com/withastro/action)

## Layout

```
content/posts/              your medmark output (one folder per slug)
public/                     static files — favicon, avatar, LOCAL images
src/site.json               name, tagline, description, links
src/content.config.ts       lenient schema over medmark front matter
src/layouts/Base.astro      page shell, header, footer, meta tags
src/lib/posts.ts            sorting, drafts, excerpts, year grouping
src/pages/index.astro       post list
src/pages/posts/[...slug].astro
src/pages/404.astro
src/pages/rss.xml.ts        RSS feed
src/pages/sitemap.xml.ts    sitemap
src/pages/robots.txt.ts     robots.txt
src/styles/global.css       all the styling, light + dark
```

Images default to Medium's CDN (`imageStorageStrategy: 'REMOTE'`). If you generated with `'LOCAL'`, copy the `resources`
folders into `public/` so the paths resolve.

Everything is deliberately small — one CSS file and two page templates. Change them.
