## Prerequisites

- Node.js 18 or later
- A Medium account export (request one from [medium.com/me/export](https://medium.com/me/export))

## Run with npx (recommended)

No installation needed:

```bash
npx medmark
```

On first run medmark will:

1. Create a `medmark/` workspace in your current directory
2. Walk you through a short interactive prompt

## Install globally

```bash
npm install -g medmark
# or
pnpm add -g medmark
```

Then run:

```bash
medmark
```

## Providing your Medium export

<Steps>

<Step>

### Request your export

Go to [medium.com/me/export](https://medium.com/me/export) and request your
information. Medium emails you a download link, which can take a little while
to arrive.

</Step>

<Step>

### Create the workspace

```bash
npx medmark init
```

</Step>

<Step>

### Drop the posts in

Unzip the archive and copy its `posts/` folder into `medmark/medium-export/`,
so you end up with `medmark/medium-export/posts/*.html`.

</Step>

<Step>

### Convert

```bash
npx medmark
```

</Step>

</Steps>

## What you get

```
medmark/output/
├── my-first-post/
│   └── index.md             ← one folder per post (folderForEachSlug)
├── registry.json            ← content registry manifest
└── conversion_report.json   ← what succeeded, failed, and was skipped
```

<Callout title="Prompts can be skipped">
Every prompt has a matching flag, so the whole run can be scripted. See the
[CLI reference](/docs/cli-reference).
</Callout>
